# Monitor adaptativo de sensores

Aplicacion Flutter que muestra una interfaz responsiva para monitorear el estado
de conectividad del dispositivo. La navegacion cambia segun el ancho de pantalla:
usa barra inferior en moviles y rail lateral en tablet/escritorio.

## Funciones

- Lectura inicial del estado de red.
- Escucha de cambios de conectividad en tiempo real.
- Panel con indicadores adaptativos.
- Vista de red con resumen de deteccion.
- Ajuste de densidad para cambiar la presentacion de las tarjetas.
- Soporte de tema claro y oscuro.

## Ejecucion

```bash
flutter pub get
flutter run
```

## Pruebas

```bash
flutter test
```
